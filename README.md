# 🥋 SUB·LOG | No-Gi Grappling Tracker

Web App progressiva (PWA) progettata specificamente per chi pratica **Grappling e BJJ No-Gi**, ottimizzata per iPhone con grafica Dark Combat, supporto offline e statistiche d'attacco.

---

## 📱 Come Hostarla Gratis su GitHub Pages (senza usare la riga di comando)

Non serve installare Git né avere competenze da programmatore: puoi fare tutto comodamente dal sito web di GitHub!

### Passo 1: Crea una Repository su GitHub
1. Vai su [github.com](https://github.com) ed esegui l'accesso (o crea un account gratuito se non ne hai uno).
2. In alto a destra clicca sul pulsante verde **"New"** (oppure vai su `github.com/new`).
3. Dai un nome al repository, ad esempio: `nogi-tracker`.
4. Assicurati che sia impostata su **Public**.
5. Clicca su **"Create repository"**.

### Passo 2: Carica i File dal Browser
1. Nella schermata successiva, cerca la scritta **"uploading an existing file"** e cliccaci sopra.
2. Trascina all'interno della finestra del browser tutti i file contenuti in questa cartella:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.json`
   - `sw.js`
   - La cartella `icons` (con `icon.svg`)
3. In basso, clicca sul pulsante verde **"Commit changes"**.

### Passo 3: Attiva GitHub Pages
1. Nella pagina del tuo repository, clicca sulla scheda **Settings** (Impostazioni) in alto.
2. Nel menu a sinistra, clicca su **Pages**.
3. Sotto **Build and deployment** $\rightarrow$ **Branch**:
   - Seleziona `main` invece di `None`.
   - Lascia la cartella su `/ (root)`.
   - Clicca su **Save**.
4. Attendi circa 30-60 secondi e aggiorna la pagina: vedrai comparire un box verde con il tuo link HTTPS, ad esempio:
   `https://tuo-username.github.io/nogi-tracker/`

## 📲 Come Installarla su iPhone come App Nativa

1. Apri **Safari** sul tuo iPhone e visita il link di GitHub Pages generato.
2. Tocca l'icona **Condividi** in basso (il quadrato con la freccia rivolta verso l'alto).
3. Scorri verso il basso e tocca **"Aggiungi alla schermata Home"**.
4. Tocca **"Aggiungi"** in alto a destra.

Ora avrai l'icona **SUB·LOG** sulla schermata Home del tuo iPhone: si aprirà a schermo intero come una vera app dell'App Store e funzionerà anche offline!

## ⚡ Alternativa Istantanea (Netlify Drop)
Se vuoi provarla sul telefono all'istante senza nemmeno fare il login su GitHub:
1. Apri [app.netlify.com/drop](https://app.netlify.com/drop) dal browser del tuo computer.
2. Trascina l'intera cartella `nogi-tap-tracker`.
3. In 10 secondi avrai un link HTTPS funzionante da aprire subito su iPhone.
